# Clean Restart — Day 1

This is a fresh project run. Keep the existing old project folder for archival reference if needed, but do not copy its results into this repository.

1. Extract this master ZIP.
2. Open the extracted `voice_clone_scam_defense_restart` folder in VS Code.
3. Run `powershell -ExecutionPolicy Bypass -File .\scripts\setup_windows.ps1`.
4. Run ` .\.venv\Scripts\python.exe .\scripts\check_env.py` (without the leading space).
5. Run the FFmpeg check.
6. Run the model benchmarks.
7. Only after these pass, Day 1 is closed.
