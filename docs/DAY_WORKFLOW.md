# Daily Workflow

1. Read the current `PROJECT_STATE.md` before doing new work.
2. Work only on the current day.
3. Modify the existing files; do not create separate day projects.
4. Run acceptance checks.
5. Record only real numbers and outputs.
6. Update `PROJECT_STATE.md`.
7. Commit and push the day's changes.

### Commit format
```text
Day 1: environment and benchmark baseline
Day 2: smoke tests and codec pipeline
...
Day 15: reproducibility and demo rehearsal
```
